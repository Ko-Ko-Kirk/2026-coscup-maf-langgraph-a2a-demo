# Code of Conduct

## Our standard

We want technical disagreement to be direct, evidence-based, and respectful.
Contributors and maintainers are expected to:

- critique code and claims rather than people;
- distinguish verified behavior from inference;
- welcome questions from people with different levels of experience;
- avoid harassment, discrimination, threats, and publication of private data;
- disclose vendor affiliation or other material conflicts when relevant.

## Scope

This standard applies in repository discussions, pull requests, issues, demos,
and other public spaces where someone represents this project.

## Enforcement

Report unacceptable behavior privately to the repository owner. Maintainers may
edit or remove content and temporarily or permanently restrict participation
when behavior threatens a safe, constructive community.

Reports will be handled as confidentially as practical. Do not include secrets
or sensitive personal information in a public issue.
